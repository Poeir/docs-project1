# Proposal Project1 — LaTeX Version

Converts the "Proposal Project1.docx" document (project outline for **Dino**: a centralized tourism web application for Khon Kaen province, Department of Computer Science, College of Computing, Khon Kaen University) into a LaTeX file that matches the original formatting, with content split into separate files by section so it can be edited/filled in later.

## File structure

```
Proposal Project1.docx      Original (Word)
latex/
├── main.tex                Preamble + \input list for each section (do not edit content here)
├── sections/                Content for each section — edit/fill in content in these files
│   ├── 00-cover.tex          Cover page
│   ├── 00-proposal-id.tex    Project proposal cover form
│   ├── 01-title.tex          1. Project title
│   ├── 02-rationale.tex      2. Rationale
│   ├── 03-objectives.tex     3. Objectives
│   ├── 04-theory.tex         4. Theory and related work
│   ├── 05-methodology.tex    5. Research methodology
│   ├── 06-scope.tex          6. Scope and limitations
│   ├── 07-location.tex       7. Research location
│   ├── 08-benefits.tex       8. Expected benefits
│   ├── 09-timeline.tex       9. Timeline (Gantt chart)
│   ├── 10-budget.tex         10. Budget
│   ├── 11-references.tex     11. References
│   └── 99-signature.tex      Advisor sign-off form
├── images/                  Images extracted from the original .docx
├── fonts/                   TH Sarabun New font (bundled with the project, no extra install needed)
└── main.pdf                 Compiled output
```

## How to compile

Requires **XeLaTeX only** (not pdflatex), because it needs Thai fonts and XeTeX's Thai line-breaking:

```bash
cd latex
xelatex main.tex
```

Run it again once if page numbers/references haven't updated yet. The output is `latex/main.pdf`.

To preview specific pages without opening a PDF reader, convert them to images:

```bash
pdftoppm -png -r 150 -f <start-page> -l <end-page> main.pdf preview
```

## Editing content

- Edit each section's content in `latex/sections/`, matching the section name — e.g. fill in the budget figures in `10-budget.tex`, or edit Chapter 4 in `04-theory.tex`.
- Section numbers (1., 4.1, 4.1.1, etc.) are generated by LaTeX's `\section`/`\subsection`/`\subsubsection` — don't type the numbers yourself, they're numbered automatically.
- The stepped indentation style (4.1 indents from 4., 4.1.1 indents from 4.1) and the spacing after each section number (4 spaces for top-level sections 1./2./3.…/11., 2 spaces for subsections) are already configured in `main.tex` — don't touch this unless you actually want to change the formatting.

## Notes

- The TH Sarabun New font is bundled directly in `latex/fonts/` (referenced by relative path in `main.tex`), so it compiles even on machines that don't have the font installed.
