% คำนำ — ปรับจากคำนำของคู่มือ "ไปนำแหน่" ให้ตรงกับฟังก์ชันของระบบไดโน
% หัวข้อ "คำนำ" และชื่อผู้จัดทำท้ายหน้าสร้างโดย environment preface ใน main.tex

เอกสารคู่มือการใช้งานเว็บแอปพลิเคชัน ``ไดโน'' ได้จัดทำขึ้นโดยมีวัตถุประสงค์เพื่อให้ผู้ใช้งานสามารถใช้งานระบบได้อย่างถูกต้องและเกิดประสิทธิภาพสูงสุด คู่มือนี้ประกอบด้วยขั้นตอนการเข้าใช้งาน การสมัครสมาชิกและเข้าสู่ระบบ การค้นหาสถานที่ท่องเที่ยวและกิจกรรม การสอบถามข้อมูลกับแชตบอต การสร้างและปรับแผนการเดินทาง การสะสมพอยท์ด้วยการสแกน QR Code ตลอดจนการใช้งานในส่วนของผู้ดูแลระบบ และขั้นตอนการติดตั้งระบบสำหรับนักพัฒนา ผู้จัดทำหวังเป็นอย่างยิ่งว่าคู่มือฉบับนี้จะเป็นประโยชน์ต่อผู้ใช้งานทุกกลุ่ม
