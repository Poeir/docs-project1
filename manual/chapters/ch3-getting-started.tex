\subsection{การสมัครสมาชิก}
\label{sec:register}

การสมัครสมาชิกทำให้บันทึกแผนทริป สะสมพอยท์ และแจ้งข้อมูลที่ไม่ถูกต้องได้ แบบฟอร์มสมัครสมาชิกแสดงดังภาพที่~\ref{fig:guest-signup-form}

\appscreen{guest-signup-form}{หน้าฟอร์มสมัครสมาชิก}

\begin{steps}
  \item คลิกปุ่ม \btn{สมัครสมาชิก} ที่มุมขวาบน
  \item กรอกข้อมูลในแบบฟอร์ม
        \begin{enumerate}
          \item \field{คำนำหน้า} \field{ชื่อ} \field{นามสกุล} \field{เพศ} \field{วันเกิด} และ \field{อาชีพ}
          \item \field{อีเมล} และ \field{เบอร์โทรศัพท์}
          \item \field{รหัสผ่าน} และ \field{ยืนยันรหัสผ่าน}
          \item ที่อยู่ปัจจุบัน ได้แก่ \field{จังหวัด} \field{อำเภอ} และ \field{ตำบล}
        \end{enumerate}
  \item ทำเครื่องหมายยินยอมให้เก็บและใช้ข้อมูลส่วนบุคคลตามนโยบายความเป็นส่วนตัว แล้วคลิกปุ่ม \btn{สมัครสมาชิก}
        \result{ระบบส่งอีเมลยืนยันไปยังอีเมลที่กรอก}
  \item เปิดลิงก์ในอีเมลภายใน 24 ชั่วโมง
        \result{ระบบยืนยันบัญชีและเข้าสู่ระบบให้อัตโนมัติโดยไม่ต้องกรอกรหัสผ่านซ้ำ}
\end{steps}

\begin{important}
รหัสผ่านต้องยาวอย่างน้อย 8 ตัวอักษร และมีทั้งตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก และตัวเลข ระบบแสดงผลการตรวจเงื่อนไขทีละข้อใต้ช่องรหัสผ่าน ถ้าอีเมลถูกใช้แล้วหรือรหัสผ่านไม่ครบเงื่อนไข ระบบจะแจ้งสาเหตุและยังไม่สร้างบัญชี
\end{important}

ถ้าพยายามเข้าสู่ระบบก่อนยืนยันอีเมล ระบบจะแจ้งว่า ``กรุณายืนยันอีเมลก่อนเข้าสู่ระบบ'' ถ้าลิงก์หมดอายุ ให้ติดต่อผู้ดูแลระบบเพื่อส่งอีเมลยืนยันใหม่ (หัวข้อ~\ref{sec:admin-users})

\subsection{การเข้าสู่ระบบ}
\label{sec:login}

แบบฟอร์มเข้าสู่ระบบแสดงดังภาพที่~\ref{fig:guest-login-form}

\appscreen{guest-login-form}{หน้าฟอร์มเข้าสู่ระบบ}

\begin{steps}
  \item คลิกปุ่ม \btn{เข้าสู่ระบบ} ที่มุมขวาบน
  \item กรอก \field{อีเมล} และ \field{รหัสผ่าน} ที่ลงทะเบียนไว้
  \item คลิกปุ่ม \btn{เข้าสู่ระบบ}
        \result{แถบเมนูเปลี่ยนเป็นแถบเมนูของสมาชิก (หัวข้อ~\ref{sec:member-menu})}
\end{steps}

\begin{note}
ระบบคงสถานะเข้าสู่ระบบไว้ 30 วันจนกว่าจะออกจากระบบ ถ้ากรอกข้อมูลผิด ระบบแจ้งข้อความทั่วไปโดยไม่ระบุว่าผิดที่อีเมลหรือรหัสผ่าน และจำกัดจำนวนครั้งที่ลองซ้ำ บัญชีที่ถูกระงับจะเข้าสู่ระบบไม่ได้
\end{note}

\subsection{การตั้งรหัสผ่านใหม่เมื่อลืมรหัสผ่าน}
\label{sec:forgot-password}

หน้าลืมรหัสผ่านแสดงดังภาพที่~\ref{fig:forgot-password}

\appscreen{forgot-password}{หน้าลืมรหัสผ่าน}

\begin{steps}
  \item ที่หน้าเข้าสู่ระบบ คลิกปุ่ม \btn{ลืมรหัสผ่าน?}
  \item กรอก \field{อีเมล} ที่ใช้สมัคร แล้วคลิกปุ่ม \btn{ส่งลิงก์รีเซ็ตรหัสผ่าน}
        \result{ระบบแสดงข้อความเดียวกันเสมอไม่ว่าอีเมลนั้นมีบัญชีหรือไม่ และส่งลิงก์ไปยังอีเมลเมื่อพบบัญชี}
  \item เปิดลิงก์ในอีเมลภายใน 1 ชั่วโมง แล้วกรอกรหัสผ่านใหม่ตามเงื่อนไขเดียวกับการสมัครสมาชิก
        \result{ระบบเข้าสู่ระบบให้บนอุปกรณ์นั้น และออกจากระบบบนอุปกรณ์อื่นทั้งหมด}
\end{steps}

ลิงก์ตั้งรหัสผ่านใหม่ใช้ได้ครั้งเดียว ถ้าลิงก์หมดอายุหรือถูกใช้แล้ว ให้ขอลิงก์ใหม่จากหน้าลืมรหัสผ่านอีกครั้ง

\label{sec:logout}

\begin{calloutlist}
  \item แถบเมนูด้านข้าง จัดเป็นกลุ่ม ได้แก่ ภาพรวม เนื้อหา คิวตรวจสอบ พอยท์และรางวัล และผู้ใช้และการใช้งาน เมนูคิวตรวจสอบแสดงจำนวนรายการที่รออยู่
  \item แท็บ \btn{ภาพรวม} \btn{ผู้ใช้และรางวัล} และ \btn{แผนทริป}
  \item ข้อความเตือน เช่น ระบบมีผู้ดูแลระบบเพียงคนเดียวและควรเพิ่มบัญชีสำรอง

  \item การ์ด ``ดัชนีค้นหาแชทบอท (Embedding)'' แจ้งจำนวนรายการที่แก้ไขแล้วแต่ยังไม่อัปเดตดัชนี พร้อมปุ่ม \btn{อัปเดตดัชนีค้นหา}
  \item การ์ดเวอร์ชันระบบ แสดงเวอร์ชันของ Frontend Backend และ Chatbot
  \item ลิงก์ \btn{ไปหน้าผู้ใช้} และ \btn{ออกจากระบบ}
\end{calloutlist}

แท็บผู้ใช้และรางวัลแสดงบัญชีที่ถูกระงับหรือยังไม่ยืนยันอีเมล พอยท์ที่คงค้างในบัญชี การแลกของรางวัลใน 30 วัน และรายการแลกล่าสุด ส่วนแท็บแผนทริปแสดงสถิติการสร้างแผนทริป
