API ของระบบแบ่งเป็น 2 ส่วน ส่วนแรกคือ REST API ของ backend จำนวน 148 รายการ ตามตารางที่~\ref{tab:api} ซึ่งสรุปจากไฟล์ \filename{backend/openapi.yaml} ส่วนที่สองคือ API ของ AI Service ตามตารางที่~\ref{tab:api-ai}

ช่องสิทธิ์ ``ทุกคน'' หมายถึงเรียกได้โดยไม่ต้องเข้าสู่ระบบ ``สมาชิก'' หมายถึงต้องเข้าสู่ระบบ และ ``ผู้ดูแลระบบ'' หมายถึงต้องเข้าสู่ระบบด้วยบัญชีบทบาท \cmd{admin} พารามิเตอร์และรูปแบบข้อมูลของแต่ละรายการดูได้จากไฟล์ดังกล่าว หรือจากหน้า \cmd{http://localhost:4000/api/docs} ขณะพัฒนา
