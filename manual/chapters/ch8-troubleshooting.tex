\section{ปัญหาที่ผู้ใช้พบบ่อย}

ปัญหาที่ผู้ใช้พบระหว่างใช้งานเว็บไซต์ พร้อมสาเหตุและวิธีแก้ไข แสดงดังตารางที่~\ref{tab:troubleshoot}

\begin{troubleshooting}[ปัญหาที่ผู้ใช้พบบ่อยและวิธีแก้ไข][tab:troubleshoot]
\problem{ไม่ได้รับอีเมลยืนยันหลังสมัครสมาชิก}
        {อีเมลอยู่ในกล่องจดหมายขยะ หรือพิมพ์อีเมลผิด}
        {ตรวจกล่องจดหมายขยะ ถ้าไม่พบหรือลิงก์หมดอายุ ให้ผู้ดูแลระบบส่งอีเมลยืนยันใหม่ (หัวข้อ~\ref{sec:admin-users})}
\problem{``กรุณายืนยันอีเมลก่อนเข้าสู่ระบบ''}
        {ยังไม่ได้เปิดลิงก์ยืนยันในอีเมล}
        {เปิดลิงก์ในอีเมลภายใน 24 ชั่วโมงหลังสมัคร}
\problem{สมัครสมาชิกไม่ได้ ระบบแจ้งว่าอีเมลถูกใช้แล้ว}
        {อีเมลนี้มีบัญชีอยู่แล้ว หรือเป็นบัญชีที่ลบไปแล้ว}
        {เข้าสู่ระบบหรือตั้งรหัสผ่านใหม่ (หัวข้อ~\ref{sec:forgot-password}) ถ้าเคยลบบัญชี ให้ติดต่อผู้ดูแลระบบเพื่อกู้คืน}
\problem{เข้าสู่ระบบไม่ได้}
        {อีเมลหรือรหัสผ่านไม่ถูกต้อง ลองซ้ำหลายครั้งเกินกำหนด หรือบัญชีถูกระงับ}
        {ตั้งรหัสผ่านใหม่ หรือรอสักครู่แล้วลองใหม่ ถ้ายังไม่ได้ให้ติดต่อผู้ดูแลระบบ}
\problem{ลิงก์ตั้งรหัสผ่านใหม่ใช้ไม่ได้}
        {ลิงก์หมดอายุ (เกิน 1 ชั่วโมง) หรือถูกใช้แล้ว}
        {ขอลิงก์ใหม่จากหน้าลืมรหัสผ่าน}
\problem{แผนทริปหายเมื่อปิดหน้าเว็บ}
        {สร้างแผนโดยไม่ได้เข้าสู่ระบบ}
        {เข้าสู่ระบบก่อนสร้างแผน ระบบจะบันทึกไว้ในเมนูทริปของฉัน}
\problem{ทำสำเนาทริปไม่ได้}
        {บันทึกแผนครบ 50 แผนแล้ว}
        {ลบแผนเก่าที่ไม่ใช้}
\problem{``ระบบแชทขัดข้องชั่วคราว''}
        {AI Service หรือผู้ให้บริการโมเดลภาษาไม่พร้อมใช้งาน}
        {ลองใหม่ภายหลัง ถ้าเป็นนานให้แจ้งผู้ดูแลระบบ}
\problem{ไม่แสดงแผนที่ในหน้ารายละเอียดหรือแบบฟอร์มวางแผนทริป}
        {เบราว์เซอร์โหลด Google Maps ไม่สำเร็จ}
        {รีเฟรชหน้าเว็บด้วย \keys{Ctrl+F5} ถ้ายังไม่แสดงให้แจ้งผู้ดูแลระบบ}
\problem{กดสแกน QR Code แล้วกล้องไม่เปิด}
        {ไม่ได้อนุญาตให้เบราว์เซอร์ใช้กล้อง}
        {อนุญาตกล้องในการตั้งค่าของเบราว์เซอร์ แล้วเปิดหน้าใหม่ หรือใช้แอปกล้องของโทรศัพท์สแกนแทน}
\problem{``สแกนไม่สำเร็จ''}
        {ดูสาเหตุตามข้อความที่แสดง}
        {ทำตามตารางที่~\ref{tab:qr-errors}}
\problem{แจ้งข้อมูลไม่ถูกต้องซ้ำไม่ได้}
        {หัวข้อนั้นเคยแจ้งแล้วและยังรอตรวจสอบ}
        {รอผู้ดูแลระบบตรวจรายงานเดิม}
\problem{ส่งคำขอเพิ่มกิจกรรมไม่ได้}
        {มีคำขอที่รออนุมัติครบ 5 รายการแล้ว}
        {รอผลของคำขอเดิม หรือยกเลิกคำขอที่ไม่ต้องการ}
\end{troubleshooting}

\section{ปัญหาการติดตั้งและดูแลระบบ}

ปัญหาที่ผู้ติดตั้ง ผู้ดูแลเครื่องแม่ข่าย หรือนักพัฒนาอาจพบ แสดงดังตารางที่~\ref{tab:troubleshoot-admin}

\begin{troubleshooting}[ปัญหาการติดตั้งและดูแลระบบ][tab:troubleshoot-admin]
\problem{\cmd{/api/health} ตอบ \cmd{{"status":"error"}}}
        {backend เชื่อมต่อฐานข้อมูลไม่ได้ เช่น \cmd{DATABASE_URL} ผิด หรือใช้พอร์ต 6543}
        {ใช้ Session pooler พอร์ต 5432 แล้วเริ่ม backend ใหม่}
\problem{API ตอบรหัส 503 ``ฐานข้อมูลยังไม่เป็นปัจจุบัน''}
        {ยังไม่ได้นำ migration ล่าสุดไปใช้}
        {นำ migration ไปใช้ตามหัวข้อ~\ref{sec:upgrade}}
\problem{\cmd{/health} ของ AI Service ไม่ตอบหลังเริ่มบริการ}
        {AI Service กำลังโหลดโมเดลสำหรับสร้าง Embedding}
        {รอสักครู่ แล้วดู \cmd{docker compose logs --tail 50 chatbot}}
\problem{AI Service ไม่เริ่ม และบันทึกแจ้ง \cmd{LLM_PROVIDER must be ...}}
        {ค่า \cmd{LLM_PROVIDER} ไม่ใช่ \cmd{kku}, \cmd{anthropic} หรือ \cmd{vertex}}
        {แก้ค่าใน \filename{chatbot.env} แล้วรัน \cmd{docker compose up -d}}
\problem{แชตบอตตอบไม่ได้ และบันทึกแจ้ง \cmd{401 Invalid model}}
        {ไม่ได้กำหนด \cmd{MODEL_NAME} หรือชื่อโมเดลไม่มีในผู้ให้บริการ}
        {กำหนด \cmd{MODEL_NAME} ให้ตรงกับรายชื่อโมเดลของผู้ให้บริการ}
\problem{เบราว์เซอร์แจ้ง \cmd{CORS error}}
        {\cmd{FRONTEND_ORIGIN} หรือ \cmd{CORS_ORIGINS} ไม่ตรงกับที่อยู่ของหน้าเว็บ หรือมี / ท้าย}
        {แก้ค่าให้ตรงทุกตัวอักษร แล้วเริ่มบริการใหม่}
\problem{สร้าง image ของ \cmd{chatbot} ไม่สำเร็จ หรือถูกหยุดกลางคัน}
        {หน่วยความจำของเครื่องแม่ข่ายไม่พอ}
        {เพิ่มหน่วยความจำหรือ swap และสร้าง image ทีละบริการด้วย \cmd{deploy.sh}}
\problem{เปิดเว็บไซต์ด้วย HTTPS ไม่ได้}
        {ชื่อโดเมนไม่ได้ชี้มายังเครื่อง หรือพอร์ต 80 และ 443 ถูกปิด Caddy จึงขอใบรับรองไม่สำเร็จ}
        {ตรวจ DNS และไฟร์วอลล์ แล้วดู \cmd{docker compose logs caddy}}
\problem{ผู้ใช้ไม่ได้รับอีเมลจากระบบเลย}
        {\cmd{GMAIL_APP_PASSWORD} ผิด หรือบัญชี Gmail ไม่ได้เปิดการยืนยันตัวตน 2 ขั้นตอน}
        {สร้าง App Password ใหม่ แก้ \filename{backend.env} แล้วเริ่ม backend ใหม่}
\problem{แชตบอตไม่พบสถานที่หรือความรู้ที่เพิ่งเพิ่ม}
        {ยังไม่ได้อัปเดตดัชนีค้นหา}
        {คลิกปุ่ม \btn{อัปเดตดัชนีค้นหา} บนแดชบอร์ด หรือรัน \cmd{python scripts/embed_content.py}}
\problem{\cmd{deploy.sh} จบด้วยสถานะผิดพลาด}
        {\cmd{/health} ไม่ตอบภายใน 3 นาที}
        {อ่านบันทึกการทำงานที่สคริปต์แสดง แก้สาเหตุ แล้วรันใหม่}
\problem{\cmd{EADDRINUSE} ขณะรัน \cmd{npm run dev}}
        {มีโปรแกรมอื่นใช้พอร์ต 4000 หรือ 5173 อยู่}
        {ปิดโปรแกรมเดิม หรือเปลี่ยน \cmd{PORT} ใน \filename{backend/.env}}
\problem{PowerShell แจ้งว่ารัน \cmd{venv\Scripts\activate} ไม่ได้}
        {นโยบายของ PowerShell ไม่อนุญาตให้รันสคริปต์}
        {รัน \cmd{Set-ExecutionPolicy -Scope CurrentUser RemoteSigned} แล้วลองใหม่}
\end{troubleshooting}
